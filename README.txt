GLOWING HEART LOVE WEBSITE

Files:
- index.html: Complete standalone website. It includes all HTML, CSS, and JavaScript in one file.

Preview:
Open index.html in a web browser.

Deploy to Netlify:
1. Extract this ZIP file.
2. Open Netlify and choose to deploy manually / drag and drop a site.
3. Upload the extracted glowing_heart_website folder (or drag index.html into a ZIP/folder deploy area supported by Netlify).
4. Netlify will provide a shareable website URL.

Customize:
Open index.html in a text editor and change the heading, messages, and signature to your own words.
